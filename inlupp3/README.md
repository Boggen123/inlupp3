## Design decision

Till början skrev vi egna test, där vi använde AI-tester för att kompletera och testa alla edgecases.

Vi följde parserns design med att använda stor första bokstav på commands

Vi tyckte instruktionerna var otydliga så vi lade Namedconstants i en separerad fil från constants

Vi har inte haft någon deal med lärare.
